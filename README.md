# AURELIA — The Golden Bloom

A cinematic, interactive **mechanical golden flower** that opens and closes with a satisfying animated motion.

Inspired by premium kinetic sculptures, the flower, stem, metallic petals, ambient particles, and light effects are all drawn procedurally in JavaScript. No downloaded 3D models, images, or animation libraries.

## Tech

- HTML5
- CSS3 (responsive layout, luxury dark-and-gold styling)
- Vanilla JavaScript and Canvas 2D

## Features

- Multi-layer mechanical petals with metallic lighting and fine veins
- Click-to-bloom and click-to-close interactions
- Smooth spring-based motion and subtle ambient movement
- Floating golden dust particles and bloom shockwave
- Mouse parallax, mobile-friendly responsive layout
- Respects `prefers-reduced-motion` (keeps interaction, removes spring movement)
- Zero external dependencies

## Getting started

Option 1: open `index.html` directly in Chrome, Firefox, or Edge.

Option 2 (recommended): open the directory in a terminal and run:

```bash
python -m http.server 8000
```

Visit <http://localhost:8000>.

## Use in a reel

Record at 1080 × 1920 (portrait) for Instagram Reels, TikTok, and YouTube Shorts. Start closed, hold the bloom button to open, and repeat from a different zoom level. For a code/output split-screen Reel, show `script.js` next to the webpage.

## Publishing to GitHub

1. Create a new **public** GitHub repository (suggested name: `aurelia-golden-bloom`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` (and optional `LICENSE`, `SOCIAL_CAPTIONS.md`).
3. Under **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`.
4. Put your actual public repository URL and GitHub Pages URL in the Reel description.
